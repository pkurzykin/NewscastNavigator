# Changelog

## [1.3.0] - подготовлено 2026-09-21, ещё не выпущено

### Added
- Начальный сценарий из четырёх блоков: Подводка → ЗК → СНХ → ЗК.
- Основной шрифт PT Sans или Franklin Gothic Book для всего сценария,
  включая автосохранение, отмену/повтор, историю, восстановление и DOCX.
- Подсветка изменённых слов и оформления в сворачиваемом сравнении истории.
- Открытие веб-ссылок материалов и копирование путей, включая UNC/SMB
  для Windows и Linux и ручное копирование при запрете браузерного доступа.
- Удаление архивного сюжета с подтверждением для сотрудников без функций
  монтажёра и дизайнера; активный сюжет удалить нельзя.

### Changed
- Единое компактное оформление списка, форм, уведомлений, сотрудников,
  рубрик, производства и панелей сценария.
- Редакционные и производственные действия размещены рядом со статусами
  этапов; «Готово к титрам» находится в этапе «Титры».
- Руководство выбирает автора в «Исполнителях» на вкладке «Производство».
- В режиме чтения инструменты сценария свёрнуты; поиск с клавиатуры
  раскрывает их. Доступ к редактированию и текущий редактор видны над таблицей.
- Формы правок и возврата озвучки сохраняют введённое при ошибке и случайном
  клике вне окна; пустая панель пакетов правок скрыта.

### Fixed
- Повторное изменение серверного текста при восстановлении черновика
  сохраняет исходный локальный текст, его шрифт и оформление.
- Первый ввод при получении права редактирования, повтор неудачного выхода
  и переходы назад/вперёд сохраняют локальный текст и рабочий контекст.
- Ошибка чтения после принятой команды позволяет повторить загрузку
  без повторного выполнения действия.
- Исправлены возврат фокуса, положение уведомлений и приоритетов,
  размеры полей сценария и панелей на рабочих экранах.
- Добавлено среднее тире через NumpadSubtract или Alt/Option+минус;
  сохранён выбор прямых кавычек и «ёлочек», GEO по умолчанию жирный курсив.

## [1.2.0] - 2026-08-23

### Added
- Общая история действий сценария с отменой и повтором для текста,
  форматирования, блоков и файлов.
- Перетаскивание блоков с сохранёнными кнопками и клавиатурным управлением.
- Умные русские кавычки, поиск и атомарная замена по текстовым полям сценария.
- Системный шрифт Franklin Gothic Book в редакторе и DOCX-экспорте.
- Доступное окно «Что нового» при первом входе пользователя в новую версию.

### Changed
- Поиск подсвечивает актуальные совпадения во всех поддерживаемых полях, а
  «Заменить всё» сохраняется как одно действие autosave и истории.

### Fixed
- Состояния подготовки DOCX больше не меняют геометрию sticky-toolbar и scroll
  на рабочем viewport 1366 px.

## [1.1.2] - 2026-08-23

### Fixed
- В полях файлов аппаратный ввод `+` с основного ряда и цифрового блока
  сохраняет ровно один знак без подмены на `+=`.
- Содержимое шапки на широких экранах выровнено с рабочей областью; название
  сервиса ведёт на главную страницу.
- Уведомления обновляются в видимой вкладке, а панель закрывается повторной
  кнопкой, кликом вне неё и клавишей Escape.

## [1.1.1] - 2026-08-14

### Fixed
- В DOCX голубая шапка показывается только на первой странице; строки таблицы
  не получают `w:tblHeader`.
- Для `life` добавлена отдельная жирная курсивная подпись «Лайф», а для
  `zk_geo` — буквальный префикс «Гео: » перед значением.
- Последовательные bundles одного файла в колонке «В кадре» объединяются в
  одну группу с именем файла и диапазонами таймингов.

## [1.1.0] - 2026-08-06

### Added
- Свободный хронометраж в шапке сценария.
- Экспорт актуального подтверждённого сценария в редактируемый DOCX.

### Changed
- Длинное название полностью переносится в синей шапке редактора.
- В DOCX название и рубрика объединены в одну центрированную шапку, а текст
  первой рабочей колонки выровнен по ширине.

## [1.0.2] - 2026-08-03

### Fixed
- Восстановлено подключение установленного CaptionPanels после Product Reset.
- Возвращены стабильные integration aliases `/projects` и `projectId` поверх единого актуального сценария.

### Security
- CaptionPanels получает отдельный ограниченный и отзывной bearer-токен только для integration API; браузерная авторизация остаётся на HttpOnly cookie.

## [1.0.1] - 2026-07-30

### Added
- Безопасное удаление неиспользованных сотрудников.
- Компактный футер с версией приложения.

### Changed
- Начальник может изменить логин сотрудника.
- HTML ревалидируется после deploy, а content-hashed assets кешируются immutable.

## [1.0.0] - 2026-07-30

### Added
- Production baseline утверждённого Product Reset.
