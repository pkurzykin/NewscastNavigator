# Документация NewscastNavigator

Начните с своей задачи. Все маршруты ведут к одному набору действующих источников.

| Мне нужно | Читать |
|---|---|
| Работать с сюжетом | [Руководство сотрудника](guides/README_RU.md) |
| Узнать требования и права | [Продукт](product/README_RU.md) |
| Разрабатывать, тестировать, менять интеграцию | [Разработка](engineering/README_RU.md) |
| Обновить сервис, проверить копии, восстановить работу | [Эксплуатация](operations/README_RU.md) |
| Продолжить текущую задачу | [Состояние проекта](PROJECT_STATE_RU.md), [планы](plans/README_RU.md) |
| Понять причину решения | [Принятые решения](decisions/README_RU.md) |
| Найти результат проверки или выпуска | [Отчёты](reports/README_RU.md) |
| Найти материал завершённого этапа | [Архив](archive/README_RU.md) |
| Обновить документацию | [Стандарт и ответственность куратора](DOCUMENTATION_POLICY_RU.md), [шаблоны](templates/README_RU.md) |

Агент начинает с [AGENTS.md](../AGENTS.md) и состояния проекта, затем читает
только источники своей задачи. Продукт задают спецификация и критерии качества;
инструкции описывают текущий порядок действий, отчёты — датированный результат.
Исторические планы не назначают работу и не дают разрешения на действия.

[История версий](../CHANGELOG.md), [права](../RIGHTS_RU.md) и
[сохранённые тексты лицензий](../LICENSES/README_RU.md) находятся рядом с проектом.
