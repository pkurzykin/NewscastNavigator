# Руководства для редакции

[Руководство сотрудника](USER_GUIDE_RU.md) ведёт от создания сюжета до эфира и архива. Начните с раздела «В начале смены», затем переходите к своей задаче: сценарий, проверка, производство или правки.

Правила продукта и полномочия подробно описаны в [спецификации](../product/SPEC_RU.md). Для интеграции титров с After Effects см. [контракт CaptionPanels](../engineering/CAPTIONPANELS_CONTRACT_RU.md). Руководство помогает работать с интерфейсом и не заменяет редакционные решения начальника или шеф-редактора.
