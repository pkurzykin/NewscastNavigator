# Проверка прав и лицензий перед выпуском

Документ фиксирует техническую проверку конкретной версии NewscastNavigator.
Он не заменяет юридическую экспертизу и не удостоверяет право собственности
на код. Заполняйте отдельную копию результатов для каждого коммерческого
релиза, указывая commit, дату, способ поставки и проверяющего.

## Способ поставки

- **Доступ к сервису на сервере владельца:** пользователю передаются браузерные
  файлы (JavaScript, CSS, шрифт); серверные Python-пакеты и Docker-образы
  пользователю не передаются.
- **Передача исходников, архива, установщика или Docker-образов:** проверяется
  всё фактически передаваемое содержимое, включая Python-пакеты, бинарные
  библиотеки, базовые образы и системные пакеты.

Ни один пункт ниже не считается выполненным только потому, что пакет указан
в lock-файле или в [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

## Для каждого релиза

- [ ] Записаны commit, версия, дата, получатель и точный состав передаваемых
      артефактов; сохранены их хеши или манифест.
- [ ] Составлена ведомость **фактически включённых** компонентов: прямых и
      транзитивных npm/Python-зависимостей, шрифтов, изображений и другого
      содержимого. Она сверена с `frontend/package-lock.json`,
      `backend/requirements.lock` и готовой сборкой.
- [ ] Для каждого включённого компонента проверены точная версия, применимая
      лицензия, правообладатели, текст лицензии и обязательные уведомления.
      Отсутствующее или неоднозначное подтверждение отмечено как препятствие
      к передаче соответствующего артефакта.
- [ ] В выдаваемых браузерных файлах или доступном получателю комплекте
      сохранены требуемые уведомления сторонних npm-пакетов и шрифта Onest.
      Проверена именно собранная версия, а не только `node_modules`.
- [ ] Перечень лицензий и уведомления обновлены после последнего изменения
      зависимостей или ресурсов.

## Дополнительно при передаче серверной сборки

- [ ] Проверены лицензии `psycopg` и `psycopg-binary` и всех библиотек,
      вложенных в бинарный пакет; приложены применимые тексты LGPL-3.0 и
      GPL-3.0 и уведомления об авторстве.
- [ ] Для `psycopg` зафиксирован применимый к фактической сборке вариант
      LGPL-3.0 § 4(d): подходящий механизм использования общей библиотеки
      либо предоставление Minimal Corresponding Source и Corresponding
      Application Code в форме, позволяющей повторно соединить приложение
      с изменённой версией библиотеки. Проверена необходимость Installation
      Information по § 4(e). Условия поставки не запрещают действия, которые
      LGPL сохраняет за получателем.
- [ ] Для каждого передаваемого Docker-образа проверены базовый образ,
      системные пакеты, их лицензии и уведомления. Название образа в
      Dockerfile не заменяет такую проверку.
- [ ] Подготовлен комплект лицензий и уведомлений, который действительно
      передаётся получателю вместе с конкретным артефактом.

## Проверка исходного кода и материалов

- [ ] Новые фрагменты кода, изображения, шрифты, шаблоны и экспорты
      сторонних сервисов имеют понятное происхождение и допустимы для
      выбранного способа коммерческого использования.
- [ ] Отдельные договорённости о пилоте, коммерческой лицензии, передаче
      исходников и данных оформлены вне репозитория, если они нужны для
      выбранного запуска.

## Текущее состояние

На 25 сентября 2026 года в репозитории есть реестр Python runtime-зависимостей,
прямых npm-зависимостей и шрифта Onest. Проверка
`backend/scripts/check_dependency_licenses.py` сверяет lock-файлы и metadata
в пределах своего охвата. Полного комплекта уведомлений по транзитивным
npm-пакетам и аудита базовых Docker-образов здесь пока нет. Поэтому этот
чек-лист нельзя отмечать выполненным для поставки образов без проверки
конкретной сборки.
