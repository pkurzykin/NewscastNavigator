# Требования к продукту

- [Спецификация](SPEC_RU.md) — назначение, модель сюжета, права и ограничения.
- [Критерии качества](EVAL_RUBRIC_RU.md) — как проверять соответствие продукту.
- [Руководство сотрудника](../guides/USER_GUIDE_RU.md) — как выполнять рабочие задачи.

Спецификация и критерии — основные источники требований. План реализует
утверждённое изменение; код подтверждает реализацию. Прежние планы и оценки
в [архиве](../archive/README_RU.md) не заменяют эти требования.

Изменение продукта принимает владелец. Автор обновляет требования и критерии
в том же изменении, куратор проверяет согласованность связанных документов.
