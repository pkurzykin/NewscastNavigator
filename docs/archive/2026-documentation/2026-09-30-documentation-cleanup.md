# Второй проход очистки документации

Основание: владелец поручил выполнить предложенный проход отбора и удаления
ненужного из текущего дерева с сохранением истории в Git. Повторное утверждение
каждого удаления внутри этого объёма не требуется.
Исходный снимок: `0cb6b13fb8ca02fdc4c1304b1a5f080fad8b9569`.

**Goal:** оставить документы и артефакты с конкретным дальнейшим применением,
удалить завершённые промежуточные материалы, сохранить доказательства и рабочие проверки.
**Architecture:** актуальные источники + небольшой отобранный архив; история
полного прежнего состава доступна по Git SHA. Исторические тесты читают
неизменяемые Git blobs, три входа действующего evaluator остаются в checkout.
**Tech Stack:** Markdown/JSON, Python stdlib, существующие pytest и Git.
**Spec:** [стандарт документации](../../DOCUMENTATION_POLICY_RU.md) и принятое
[решение о структуре](../../decisions/2026-09-30-documentation-system.md).
**Execution:** координатор интегрирует отбор; ограниченные workers адаптируют
backend tests и checker. Независимые reviewer, verifier и куратор проверяют результат.

## Проверки

- Сверить каждое удаление с доступным Git blob и сохранённым SHA-256.
- Проверить retained PNG/JSX/tokens на неизменность; manifests соответствуют checkout.
- Checker unit tests; реальная документация в рабочем дереве и чистом клоне с историей.
- Backend document/repository/legacy/evaluator/evidence tests на синтетической SQLite.
- Тесты installer runbook по риску, если меняется связанный путь; путь остаётся прежним.
- `git diff --check`, отсутствие неизвестных изменений, независимые заключения.

## Review Focus

1. Удаление не теряет уникальные актуальные требования или инструкции восстановления.
2. Исторические данные проверяются по точному commit; PASS не переносится на другой снимок.
3. Адаптация тестов не отключает действующие gates и не меняет evaluator CLI.
4. Новый файл в архиве не остаётся вне навигации и структурного контроля.
5. Локальные данные не удаляются только потому, что Git их игнорирует.

Внешние Git-действия, серверы и приложение не запускаются. Рабочая ветка остаётся
`codex/documentation-system`; исходное дерево чистое. План исполнен в границах
прямого поручения владельца.
