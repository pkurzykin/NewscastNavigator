## Стенд

Отдельный Compose project `ncn-ui-system-preview`, только loopback:
интерфейс `http://127.0.0.1:5173`, API `http://127.0.0.1:8100`, PostgreSQL 5433.
База заполнена каноническим synthetic seed; создан учебный сюжет 36
«Проверка редактора — учебный сюжет». Это одноразовые демонстрационные данные.
Стенд оставлен работающим для приёмки Павлом.

В Colima bind mount `/private/tmp/NewscastNavigator-ui-system/backend` оказался
пустым, хотя собранный образ содержал `app`. Локальный QA override сбрасывает
bind mounts backend/frontend и использует исходники из собранных образов.
Канонический `compose.yaml`, настройки Colima и основной checkout не менялись.
При изменении кода стенд требует пересборки образа.

Команда запуска/обновления из worktree:

```bash
docker compose --project-name ncn-ui-system-preview \
  --env-file output/playwright/local-preview.env \
  -f compose.yaml -f output/playwright/local-preview.override.yaml \
  up --build --wait
```

Для остановки с сохранением данных заменить последнюю строку на `down`.
Конфигурация и журналы лежат в `output/playwright/`, не коммитятся.
Вход synthetic seed: `astra`, пароль `Synthetic-Demo-2026!`.
Это публичные тестовые реквизиты из seed, не реальные учётные данные.
