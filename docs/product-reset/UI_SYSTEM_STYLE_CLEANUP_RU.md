- Синяя шапка `#BEDCE6` сохранена; поля и заголовки получили плотность макета.

  Палитра — цветные точки внутри небольших прямоугольных кнопок.
- Полоса доступа отражает чтение, собственную сессию, занятость и ошибку.
  Переходы lease и сохранения не менялись.

Пять колонок, все типы/поля, несколько файлов и TC, drag и стрелки, выделение,

## Что найдено и очищено

Подозрение о смешении стилей подтвердилось: в CSS оставались повторные правила,
хвостовые overrides и синий default для любой native-кнопки. Выполнен inventory
всех 11 CSS, MUI-темы, порядка импортов и визуальных inline/sx-значений компонентов.

| Область | Результат |
|---|---|
| `tokens.css`, `theme.ts` | Общие semantic borders, backdrop и тени controls/actions/header |
| `base.css` | Нейтральная базовая кнопка; синий акцент только для явного primary |
| `layout.css` | Сохранена принятая геометрия шапки; общие тени и backdrop |
| `stories.css` | Объединены повторные правила заголовков; состояния и счётчик архива унифицированы |
| `scenario.css` | Объединены 13 повторных правил; удалены прежняя чёрная сетка, цветные add-button overrides, divider и лишнее выравнивание TC |
| `history.css` | Убрана лишняя внешняя белая карточка; оставлены карточки сеансов, цветное сравнение и действия |
| `production.css` | Объединены определения панели; единые белые секции на тёплом фоне |
| `corrections.css`, `external-approval.css` | Единые рамки, радиусы, плотность подписей и состояния |
| `notifications.css` | Объединены повторы; toggle использует общий text-button |
| `admin.css` | Общие backdrop и типографика таблицы/форм |

Проверены список, архив, производство, история, сотрудники, уведомления,
профиль, вход/смена пароля, рубрики, создание сюжета, исполнители, материалы,
правки и диалоги. Это одна система оформления; параллельного legacy-режима нет.
Парсер PostCSS не нашёл точных повторов селекторов в одинаковом at-rule-контексте
во всех 11 CSS. Это структурная проверка, дополненная осмотром настоящего render.
`!important` остался только в глобальной защите `prefers-reduced-motion`.
