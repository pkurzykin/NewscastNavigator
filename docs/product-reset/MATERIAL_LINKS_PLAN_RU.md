# Материалы: веб-ссылки и копирование путей

Статус: выполнено и проверено локально; пользователь утвердил вариант без установки компонентов.
Предварительный анализ выполнен на MaterialsList.tsx и действующем контракте API.

## Утверждённый вариант

- HTTP(S)-адрес открывается в отдельной вкладке без доступа к opener.
- Локальный путь копируется кнопкой «Копировать путь»; парные внешние кавычки
  убираются для отображения/копирования, сохранённое значение не изменяется.
- UNC/SMB сетевой адрес имеет два действия: «Для Windows» (UNC), «Для Linux»
  (SMB URI). Пробелы, кириллица и специальные символы сохраняют значение.
- Адрес сервера не угадывается из буквы диска или /Volumes.
- Подтверждение появляется только после успешного копирования. Без Clipboard API
  используется копирование браузером; если оно запрещено, появляется выделенное
  поле для ручного Ctrl+C/⌘C. Файлы и папки автоматически не открываются.
- Локальный компонент, расширения, изменение политик и загрузка файлов исключены.

## Файлы и проверки

- `frontend/src/features/production/materialLocation.ts` и `.test.ts`:
  чистый разбор адреса, HTTP(S) allowlist, UNC/SMB conversion, тесты RED/GREEN.
- `frontend/src/features/production/components/MaterialsList.tsx`, новый
  `MaterialLocation.tsx`, `MaterialsList.test.tsx`: ссылки и состояние копирования,
  ошибки, ручное копирование, возврат focus. Без изменений payload/backend.
- `frontend/src/styles/production.css`: компактные действия в принятом стиле.
- `frontend/e2e/production-workflow.spec.ts`: web popup, оба формата сетевого пути,
  clipboard failure/manual selection, неизменность материала и отсутствие POST.
- `docs/design/UI_SYSTEM_RU.md`, `docs/product-reset/PROGRESS.md`: результат.
