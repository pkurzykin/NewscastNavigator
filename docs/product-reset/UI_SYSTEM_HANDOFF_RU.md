  имя держателя lease, сохранение первого ввода и локального текста при ошибках.

  для autosave/undo/draft/history/restore/DOCX; ручные шрифты сохраняются.
- Новые сценарии: Подводка → ЗК → СНХ → ЗК ровно один раз. Перетаскивание

- Удаление из архива с подтверждением; наличие монтажёра/дизайнера запрещает
  удаление при любом совмещении. Общие справочники и внешние файлы сохраняются.
- История: цветные del/ins, понятные изменения оформления/шрифта, повторное
  сворачивание, защита от позднего раскрытия, рабочее восстановление и no-op.

Синяя шапка и функции таблицы сохранены. Последняя непринятая проба её

## Решения контроллера и цена ошибки

Это все Ruling из рабочего ledger в порядке принятия.

1. Использовать worktree в `/private/tmp`, чтобы сохранить основной checkout.
   Цена: отдельные зависимости и необходимость сохранять локальные QA-артефакты.
2. Следовать текущему утверждённому UI-плану поверх завершённого Product Reset,
   не запускать CP1–CP7 заново. Ошибка трактовки потребовала бы пересмотра плана;
   повторное выполнение старых этапов создало бы несвязанные изменения.
3. Разрешить параллельную подготовку и работу root только в независимых файлах,
   при одном implementer-субагенте. Цена ошибки — интеграционный конфликт/перепроверка.
4. Разрешить Task3 одновременно с оставшейся работой списка/производства после
   передачи ему общего author-контрола. Цена ошибки — конфликт в общей странице;
   покрыто совместными тестами и отдельным ревью.
5. Разрешить root подготовить backend шаблона/удаления во время завершения Task3,
   не затрагивая editor/access файлы. Цена ошибки — интеграционная доработка;
   покрыто backend/PostgreSQL/font проверками.
6. Разделить Task5 и R-012: worker владел atomic font/semantic/backend restore,
   root — шестью UI-файлами Истории и связанными тестами. Цена ошибки — рассогласование
   интерфейса; закрыто совместными тестами и двумя независимыми reviews.

   отсутствующий шрифт. Цена: установка шрифтов остаётся платформенной проверкой;
   строгий Mac-прогон выполнен.
