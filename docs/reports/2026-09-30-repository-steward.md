## Реализация

Общая роль repository-steward явно задаёт `gpt-6-sol/high`; глобальное
значение default effort приведено с xhigh к high. Остальные настройки
config.toml сохранены; изменение файла не доказывает смену уже запущенной сессии.
Глобальные AGENTS задают вызов куратора и шесть отдельных этапов результата.
Эти настройки находятся вне репозитория, локальны этой установке Codex.

В проекте закреплены разрешённые цепочки, свежие head/base и CI, сохранность
SHA доказательств, fast-forward синхронизация и проверка ignored данных/активных
задач перед очисткой worktree. Исправлены общие инструкции, профильные документы
и шаблоны; правила имеют один основной источник в Git workflow.
