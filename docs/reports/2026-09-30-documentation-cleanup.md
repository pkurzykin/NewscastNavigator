## Отбор

Из первоначальных 122 архивных файлов сохраняются 20: три approved-baseline
комплекта (17 файлов), предыдущий закрытый план, индекс и манифест доказательств.
102 файла удалены из текущего дерева: промежуточные макеты, экспорты и прототипы,
старые промпты, планы и подробные отчёты закрытых этапов. Существенный итог
CP4–CP5 перенесён в [эксплуатационный снимок](2026-09-30-operations-baseline.md).
Старая карта первого прохода не переписывается задним числом.

Ещё шесть исторических файлов удалены из checkout. Их исходные байты и хеши
проверяются по Git `09d4c52`, без отмены содержательных тестов. Три входа
существующего evaluator остаются на прежних путях; его CLI не изменяется.
Всего удалено 108 tracked файлов, 6 493 915 байт прежнего рабочего дерева.
Это не уменьшение объёма Git history: каждый файл восстанавливается по карте.

README эталонов сокращены до назначения, состава и происхождения. PNG/JSX/tokens
сохранены побайтно. Манифесты пересчитаны после изменения README и очищены
от записей о локальных AppleDouble-файлах. CI теперь проверяет их состав и хеши,
а также паспорта, ссылки и достижимость всех оставшихся архивных Markdown.

Backend проверен из `backend/` временного клона Python-интерпретатором
существующего `backend/.venv` основного checkout:

```bash
DATABASE_URL=sqlite+pysqlite:////private/tmp/newscast-docs-cleanup-verify-tests.db \
ENVIRONMENT=test SEED_DEMO_DATA=false "$source_python" -m pytest -q \
  tests/test_current_docs.py tests/test_repository_policy.py \
  tests/test_legacy_gate.py tests/test_product_reset_eval.py \
  tests/test_historical_evidence.py
```

`source_python` — абсолютный путь к указанному интерпретатору. До финального
снимка тест обнаружил неверное предположение, что каталог с остатками AppleDouble
полностью отсутствует; проверка исправлена на отсутствие архивных Markdown.
Окончательный единый прогон выше выполнен после исправления.

## Завершение и границы

План завершён и перенесён в архив со ссылкой на этот результат. Текущая точка
обновлена, активных планов этого прохода нет. После оформления закрытия
координатор повторил `python3 scripts/check_docs.py`: PASS, 51 документ и
276 ссылок; `git diff --check` и staged diff check: PASS. Затронутые текущими
документами `test_current_docs.py` и `test_repository_policy.py` повторены:
15 PASS на отдельной синтетической SQLite. Продуктовый код и проверенные
backend-файлы при закрытии не менялись.

Три retained входа evaluator и 82 локальных CP7-файла сохранены по установленной
зависимости. Исторические 11 ссылок на 9 отсутствующих UI PNG не превращены
в новые доказательства. Для проверки Git blobs нужна полная история;
архив исходников без `.git` её не заменяет. Удалённые tracked материалы
восстанавливаются по карте; удалённые локальные временные результаты в Git
не хранились. Очистка рабочего дерева не уменьшает историю репозитория.

Серверы, сервис, browser, deploy и CI в этом проходе не запускались. Проверки
локальные и структурные; они не заявляют новый выпуск или новую приёмку
продукта. Внешние Git-действия требуют отдельного поручения владельца.
