Из первоначальных 122 архивных файлов сохраняются 20: три approved-baseline
комплекта (17 файлов), предыдущий закрытый план, индекс и манифест доказательств.
102 файла удалены из текущего дерева: промежуточные макеты, экспорты и прототипы,
старые промпты, планы и подробные отчёты закрытых этапов. Существенный итог
CP4–CP5 перенесён в [эксплуатационный снимок](2026-09-30-operations-baseline.md).
Старая карта первого прохода не переписывается задним числом.

Ещё шесть исторических файлов удалены из checkout. Их исходные байты и хеши
проверяются по Git `09d4c52`, без отмены содержательных тестов. Три входа
существующего evaluator остаются на прежних путях; его CLI не изменяется.
Всего удалено 108 tracked файлов, 6 493 915 байт прежнего рабочего дерева.
Это не уменьшение объёма Git history: каждый файл восстанавливается по карте.

README эталонов сокращены до назначения, состава и происхождения. PNG/JSX/tokens
сохранены побайтно. Манифесты пересчитаны после изменения README и очищены
от записей о локальных AppleDouble-файлах. CI теперь проверяет их состав и хеши,
а также паспорта, ссылки и достижимость всех оставшихся архивных Markdown.
