## Независимая проверка

Исходный кандидат: `48d44ca02e773326d9282fd46051eee1d62cfdf3`.

- **NN-DOCS-VERIFY:** структурный PASS; независимо проверены 100/100 исходных
  Markdown, 162/162 назначения, 62/62 вспомогательных файла и 9/9 замороженных
  свидетельств. В чистом `git archive` экспорте с новым индексом (657 файлов)
  повторно прошли 12 тестов checker и проверка 45 документов/288 ссылок.
  Парсинг трёх TOML и команды CI проверены. Серверы и приложение не запускались.
- **NN-DOCS-CURATOR:** сопровождение закреплено согласованно в policy, AGENTS,
  ролях, шаблонах, PR и релизе. Исправлена устаревшая подпись ссылки в Git workflow.
- **NN-DOCS-REVIEW:** найдены две ошибки. Установщик ещё искал runbook на старом
  пути, поэтому мог пропустить RESTORE.md; путь адаптирован, отсутствие файла
  теперь останавливает установку до создания runtime. Версионный абзац про
  закрытый deploy 1.1.0 заменён общими условиями обновления demo и восстановления.
  Дополнительно июльский npm audit вынесен в исторический отчёт; его результаты
  не объявлены текущими. Исходное требование остановиться при несовпадении
  модели координатора сохранено.

Локальная проверка исправления упаковки: 5 тестов `test_release_guard.py`
прошли; `bash -n deploy/hostland/install_release.sh` прошёл. Два новых теста
сначала воспроизвели отсутствие RESTORE.md и ошибочный успех без runbook,
после исправления оба прошли. Проверяется временная синтетическая установка;
только в тестовой копии скрипта пути перенаправлены в temporary directory,
проверка реального runtime заменена заглушкой. Production guards сохранены.

Для затронутых эксплуатационных файлов классификация: `.github/workflows/ci.yml`
— ADAPT (проверка документации); `deploy/hostland/install_release.sh` — ADAPT
(источник runbook и отказ при отсутствии). `build_full_backup.sh` — KEEP:
он включает появившийся runtime RESTORE.md по прежнему правилу. Сервисы,
БД и конфигурации сред этим этапом не изменяются.

Повторная независимая проверка исправленного снимка выполняется. Завершение плана и
итоговая точка продолжения оформляются после неё.

Исторические ссылки замороженных свидетельств применимы к исходному Git SHA;
ignored-артефакты не обещаются в чистом клоне. Установленный сервис, серверы и внешние URL
не проверяются в рамках этого изменения. Упаковка инструкции восстановления
проверяется отдельно на синтетическом временном runtime.
