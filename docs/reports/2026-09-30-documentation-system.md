## Ограничения

Новый remote CI, установка сервиса и настоящий backup/restore не запускались.
Проверка временной упаковки не доказывает восстановление рабочей БД.
Исторический статус сервиса принят по сообщению владельца; новой эксплуатационной
аттестацией этот отчёт не является. Внешние Git-действия и deploy не выполнялись.

Исторические ссылки замороженных свидетельств применимы к исходному Git SHA;
ignored-артефакты не обещаются в чистом клоне. Установленный сервис, серверы и внешние URL
не проверяются в рамках этого изменения. Упаковка инструкции восстановления
проверяется отдельно на синтетическом временном runtime.
