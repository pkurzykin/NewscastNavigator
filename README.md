# NewscastNavigator

Внутреннее веб-приложение телередакции для работы на компьютере.

> Один сюжет — один актуальный сценарий — одна понятная цепочка работы.

Сотрудники видят общую очередь сюжетов и свои действия. Карточка объединяет
сценарий, производство и историю. Из актуального сценария можно выгрузить
DOCX и получить данные для CaptionPanels.

## Устройство проекта

- `frontend/` — React, TypeScript, Vite, TipTap; [вход для разработчика](frontend/README.md).
- `backend/` — FastAPI, SQLAlchemy, Alembic, PostgreSQL; [вход для разработчика](backend/README.md).
- `deploy/` — конфигурации и скрипты сред; [назначение каталогов](deploy/README.md).
- `docs/` — требования, инструкции, решения и история.

Изменения разрабатываются в отдельной ветке, проверяются на изолированных
данных и принимаются на постоянном домашнем тестовом сервере. Выпуск на VDS
проходит отдельное согласование. Локальный запуск и точные команды — в
[инструкции разработки](docs/engineering/LOCAL_DEV_WORKFLOW_RU.md).
